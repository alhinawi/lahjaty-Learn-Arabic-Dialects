# Dialect selector return routes

Only actual destinations emitted by change-dialect chips can trigger select-and-return: home, lessons, real lesson categories, dictionary, real dictionary topics, practice and flashcards. A single trailing slash is accepted. Other next parameters fall back to normal dialect browsing, without changing the learner's selected dialect or navigating to the supplied destination.

No content, audio, sources, hosting, storage or account-policy changes. Tests cover all emitted destinations and external, executable, encoded and malformed inputs. This is a defensive navigation fix; no exploitation is claimed.
