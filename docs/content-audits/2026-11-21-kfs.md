# Kafr El-Sheikh location-claim review

Reviewed November 21, 2026. Scope: three existing `kfs` entries in `src/content/famous.json`. No entries added or removed.

## Change

Qallin, El-Riyad and Bila now have the narrow description that each is a city and district in Kafr El-Sheikh Governorate. The examples repeat only that administrative relationship.

Removed unsupported detail:

- Qallin: Rosetta-branch location and the Nile/El-Mahalla example.
- El-Riyad: eastern-governorate location, Nile frontage, facing Shirbin and the Damietta example.
- Bila: Cairo-Alexandria agricultural-road location and the Tanta example.

This change does not claim that every removed detail has been disproved. It removes detail that the checked sources do not support. It avoids replacing one precise location claim with another based only on a secondary overview.
