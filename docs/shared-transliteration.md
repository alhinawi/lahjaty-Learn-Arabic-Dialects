# Stored transliteration on everyday shares

Everyday share pages retain the selected variant's stored transliteration when the learner's existing transliteration preference is enabled. The line keeps left-to-right direction in either interface language. Disabling the preference hides it. Famous expressions and variants without transliteration do not gain an invented line.

No wording, transliteration values, sources, recordings or hosting changes. Showing a stored transliteration is not phonetic, native-speaker or lexical verification. Existing note citation scope remains unchanged.

The share card offers the same transliteration toggle used elsewhere, only when a stored line exists. Existing saved-preference rehydration is outside this patch and requires a separate fix.
