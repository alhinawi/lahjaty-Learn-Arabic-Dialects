# Dictionary search keyboard controls

The existing dictionary matcher and ten-result limit are unchanged. Up/down wrap through loaded hits, Enter opens only an explicitly selected word, Escape dismisses, and edits/focus reset the cursor. Pointer links still work. Active result IDs, expanded/selected state and a visible border identify the cursor while focus stays in the search field. Clear uses the existing translated label.

No new content, audio, sources or hosting changes. Existing lexical and native-review limits remain.
