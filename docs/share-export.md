# Compact share-page export

The site uses Next.js static export on Cloudflare Pages Free. Pages Free has a 20,000-file limit. Exporting every phrase/dialect combination as a separate HTML page made the site undeployable.

## Routing

- There is now one static `/share/` page.
- Existing `/share/<dialect>/<phrase>` links, with or without a trailing slash, receive a 302 redirect to `/share/?dialect=<dialect>&phrase=<phrase>`.
- The two rules live in `public/_redirects` and are copied into the export. They do not match `/share/`, so there is no redirect loop.
- The share page resolves identifiers against the same complete phrase data. Unknown or missing identifiers show the existing not-found screen.
- Stable legacy links remain the URLs generated by share buttons. Downloadable famous-phrase images still use their existing `/og/p/...jpg` paths.
- The service-worker cache version changes so old cached share HTML is not retained indefinitely.

## Tradeoff

The HTML shell has a generic, noindex social preview. JavaScript is needed to show the chosen phrase. Crawlers that do not run JavaScript no longer receive a phrase-specific title/card from share links. Famous-phrase card downloads remain available. No phrase, translation, dialect or audio data is removed.

## File budget

`npm run build` generates the static export and OG cards, preserves Next router payloads (`index.txt` and `__next*.txt`), then runs `npm run export:check`. It fails above 15,000 files, leaving at least 5,000 files of margin below the Pages Free limit. Count the final upload directory, not only HTML pages. No OG-card reduction is needed.

## Verification

- Unit tests cover both legacy slash forms for all current famous/everyday share targets, plus the file counter and rejection above budget.
- Run `npx wrangler pages dev out --port 8789` to test actual Pages redirect parsing locally.
- Check a famous link, an everyday link, a direct query link and invalid identifiers in a browser.
- Verify the famous-card image download, the Monufia correction notes, and mobile layout.
- Deployment verification must repeat representative redirects and confirm the Monufia notes on the live site.

## Router payloads are required

Do not delete exported `.txt` payloads to reduce file counts. Next client navigation and prefetch request these assets. Deleting them produces 404s and can force a hard reload or leave navigation incomplete. The compact share route keeps the complete export comfortably below the budget without removing router files. The budget gate counts those files too.
