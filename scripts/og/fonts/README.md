# Fonts for the social cards

Used only at build time by `scripts/og` to draw the Open Graph cards. All are under the SIL Open Font License 1.1.

- El Messiri Bold (static instance of the variable font), from google/fonts `ofl/elmessiri`
- IBM Plex Sans Arabic Bold and Medium, from google/fonts `ofl/ibmplexsansarabic`
- Noto Naskh Arabic Bold, fallback for rare letters
